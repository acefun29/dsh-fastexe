# DeepSeek Harness 便携版（Windows）— dsh-fastexe

[English](#english)

DeepSeek Harness（`dsh`）的 **Windows 便携启动器 + 完整功能包**。双击 `dsh.exe` 即可启动完整的 DeepSeek Harness Web UI（http://127.0.0.1:3080），所有功能与源码版一致：Web 界面、全部插件、多模型供应商、环境变量密钥解析。

上游项目：[deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)（MIT License）

---

## 目录结构

```
DeepSeekHarness/
├── dsh.exe        # 启动器：启动服务并自动打开浏览器（双击运行）
├── launcher.cs    # 启动器源码（C#，可用系统自带 .NET Framework 编译）
├── build-launcher.ps1   # 重新编译 dsh.exe 的脚本
├── build-package.ps1    # 从零组装整个便携包的脚本
├── node/          # 便携 Node.js 运行时（构建时生成，不入库）
└── harness/       # DeepSeek Harness 源码 + 依赖 + 构建产物（构建时生成，不入库）
```

> 本仓库只包含启动器与构建脚本；`node/` 与 `harness/`（合计约 1.3GB）由
> `build-package.ps1` 在本地组装，或直接使用仓库 Release 中的完整压缩包。

## 快速开始

1. **下载**：克隆本仓库后运行 `build-package.ps1` 组装完整包；或直接下载 Release 里的 `DeepSeekHarness-<version>.zip` 并解压。
2. **配置密钥**：将模型供应商的环境变量写入 Windows 系统环境变量，例如：
   ```
   OPENCODE_GO_API_KEY=sk-xxxx
   DEEPSEEK_API_KEY=sk-xxxx
   ```
   设置后重启资源管理器（或注销重登）使其生效。Web 界面也可以填写 API Key，但环境变量优先且更安全（密钥不落盘）。
3. **运行**：双击 `dsh.exe`。
   - 首次启动需编译，等待约 10-60 秒；
   - 自动打开浏览器访问 http://127.0.0.1:3080；
   - 控制台窗口显示服务日志，**关闭窗口即停止服务**；
   - 若 3080 端口已有实例在运行，则直接打开浏览器，不会重复启动。

## 系统要求

- Windows 10 / 11 x64
- 无需预装 Node.js（包内自带便携 Node 24）
- 首次运行需联网（自动初始化 `~/.dsh` 用户 profile）

## 从零构建完整包

前置：Windows 10+、git、curl、Node.js ≥ 22.19（用于跑 pnpm，构建完成后可卸载）。

```powershell
# 1. 组装完整便携包（下载 Node、克隆上游、安装依赖、构建、编译启动器）
.\build-package.ps1

# 2. （可选）单独重新编译启动器
.\build-launcher.ps1
```

构建产物输出到 `DeepSeekHarness/` 目录。整个包约 1.3GB，可整体拷贝到任意 Windows 机器使用。

# English

**dsh-fastexe** — a Windows portable launcher + full-feature package for
[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (`dsh`).

Double-click `dsh.exe` to boot the complete DeepSeek Harness Web UI at
http://127.0.0.1:3080 — identical to running from source: full web UI, all
plugins, multiple model providers, and environment-variable API keys.

## Layout

```
DeepSeekHarness/
├── dsh.exe                # Launcher: starts the service and opens your browser
├── launcher.cs            # Launcher source (C#, compiles with built-in .NET Framework)
├── build-launcher.ps1     # Rebuilds dsh.exe
├── build-package.ps1      # Assembles the whole portable package from scratch
├── node/                  # Portable Node.js runtime (generated by build, not tracked)
└── harness/               # Harness source + deps + build output (generated, not tracked)
```

`node/` and `harness/` (~1.3 GB total) are **not committed** to this repo.
Run `build-package.ps1` to assemble them locally, or download the full
`DeepSeekHarness-<version>.zip` from the Releases page.

## Quick start

1. **Get the package**: run `build-package.ps1` after cloning, or extract the
   Release zip.
2. **Set API keys** as Windows *system* environment variables, e.g.:
   ```
   OPENCODE_GO_API_KEY=sk-xxxx
   DEEPSEEK_API_KEY=sk-xxxx
   ```
   Restart Explorer (or sign out/in) afterwards. Keys set in the web UI also
   work, but environment variables are preferred — nothing is written to disk.
3. **Run**: double-click `dsh.exe`.
   - First start compiles the app (10-60 s);
   - your browser opens http://127.0.0.1:3080 automatically;
   - the console window shows server logs; **closing it stops the service**;
   - if port 3080 is already serving, the launcher just opens the browser.

## Requirements

- Windows 10 / 11 x64
- No Node.js needed at runtime (portable Node 24 is bundled)
- Internet on first run (bootstraps `~/.dsh` user profile)

## Build the full package from scratch

Prereqs: Windows 10+, git, curl, Node.js ≥ 22.19 (only needed to run pnpm).

```powershell
# 1. Assemble everything (download Node, clone upstream, install, build, compile launcher)
.\build-package.ps1

# 2. (Optional) rebuild only the launcher
.\build-launcher.ps1
```

Output goes to `DeepSeekHarness/`. The whole folder (~1.3 GB) can be copied to
any Windows machine and run as-is.
